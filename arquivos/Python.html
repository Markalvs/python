Pela imagem, parece que você já está em um repositório Git (vejo o main* no canto inferior esquerdo, o * indica que há alterações não salvas no Git).

Método pelo VS Code (mais fácil)

  1. Salve o arquivo (Ctrl + S).

  2. Clique no ícone Source Control (🌿) na barra esquerda.

  3. Você verá os arquivos modificados.

  4. Clique no + ao lado de cada arquivo (ou em Stage All Changes).

  5. No campo de mensagem, escreva algo como:

Adiciona exercício sobre if, elif, else e operadores relacionais

  1. Clique em Commit (✓).

  2. Clique em Sync Changes ou Push para enviar ao GitHub.

Método pelo terminal (importante aprender)

No terminal do VS Code:

Bash
git status

Veja quais arquivos foram alterados.

Depois:

Bash
git add .

Em seguida:

Bash
git commit -m "Adiciona exercício sobre if, elif e else"

E por fim:

Bash
git push

Eu recomendo aprender pelo terminal

Como você está estudando Git, vale a pena criar esse hábito. Na prática, você vai usar sempre esta sequência:

Bash
git status
git add .
git commit -m "Mensagem"
git push

São apenas 4 comandos, mas eles representam cerca de 90% do uso diário do Git por muitos desenvolvedores.

Se quiser, podemos fazer esse primeiro push juntos, comando por comando. Você executa um, me mostra o resultado, e eu digo o próximo. Assim você entende o que cada comando faz, em vez de apenas decorar.
